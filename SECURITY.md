# Security policy

BERT Console is a read-only beta interface, not a security boundary for BERT contracts. For a vulnerability in this console or its API routes, use the [BERT Core private security advisory channel](https://github.com/Tenyokj/bert-core-arc/security/advisories/new). Do not publish exploit details or secrets in an issue or pull request.

Include the affected route, reproduction steps, expected and observed behavior, and whether any secret or upstream endpoint could be exposed or exhausted. For onchain protocol vulnerabilities, use the same private channel and identify the affected contract and chain.
